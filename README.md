# Интернет-магазин «Web-Larёk»

«Web-Larёk» — это интернет-магазин с товарами для веб-разработчиков, где пользователи могут просматривать товары, добавлять их в корзину и оформлять заказы. Сайт предоставляет удобный интерфейс с модальными окнами для просмотра деталей товаров, управления корзиной и выбора способа оплаты, обеспечивая полный цикл покупки с отправкой заказов на сервер.

## Архитектура приложения

Код приложения разделен на слои согласно парадигме MVP (Model-View-Presenter), которая обеспечивает четкое разделение ответственности между классами слоев Model и View. Каждый слой несет свой смысл и ответственность:

Model - слой данных, отвечает за хранение и изменение данных.  
View - слой представления, отвечает за отображение данных на странице.  
Presenter - презентер содержит основную логику приложения и отвечает за связь представления и данных.

Взаимодействие между классами обеспечивается использованием событийно-ориентированного подхода. Модели и Представления генерируют события при изменении данных или взаимодействии пользователя с приложением, а Презентер обрабатывает эти события используя методы как Моделей, так и Представлений.

### Базовый код

#### Класс Component

Является базовым классом для всех компонентов интерфейса.
Класс является дженериком и принимает в переменной `T` тип данных, которые могут быть переданы в метод `render` для отображения.

Конструктор:  
`constructor(container: HTMLElement)` - принимает ссылку на DOM элемент за отображение, которого он отвечает.

Поля класса:  
`container: HTMLElement` - поле для хранения корневого DOM элемента компонента.

Методы класса:  
`render(data?: Partial<T>): HTMLElement` - Главный метод класса. Он принимает данные, которые необходимо отобразить в интерфейсе, записывает эти данные в поля класса и возвращает ссылку на DOM-элемент. Предполагается, что в классах, которые будут наследоваться от `Component` будут реализованы сеттеры для полей с данными, которые будут вызываться в момент вызова `render` и записывать данные в необходимые DOM элементы.  
`setImage(element: HTMLImageElement, src: string, alt?: string): void` - утилитарный метод для модификации DOM-элементов `<img>`

#### Класс Api

Содержит в себе базовую логику отправки запросов.

Конструктор:  
`constructor(baseUrl: string, options: RequestInit = {})` - В конструктор передается базовый адрес сервера и опциональный объект с заголовками запросов.

Поля класса:  
`baseUrl: string` - базовый адрес сервера  
`options: RequestInit` - объект с заголовками, которые будут использованы для запросов.

Методы:  
`get(uri: string): Promise<object>` - выполняет GET запрос на переданный в параметрах ендпоинт и возвращает промис с объектом, которым ответил сервер  
`post(uri: string, data: object, method: ApiPostMethods = 'POST'): Promise<object>` - принимает объект с данными, которые будут переданы в JSON в теле запроса, и отправляет эти данные на ендпоинт переданный как параметр при вызове метода. По умолчанию выполняется `POST` запрос, но метод запроса может быть переопределен заданием третьего параметра при вызове.  
`handleResponse(response: Response): Promise<object>` - защищенный метод проверяющий ответ сервера на корректность и возвращающий объект с данными полученный от сервера или отклоненный промис, в случае некорректных данных.

#### Класс EventEmitter

Брокер событий реализует паттерн "Наблюдатель", позволяющий отправлять события и подписываться на события, происходящие в системе. Класс используется для связи слоя данных и представления.

Конструктор класса не принимает параметров.

Поля класса:  
`_events: Map<string | RegExp, Set<Function>>)` - хранит коллекцию подписок на события. Ключи коллекции - названия событий или регулярное выражение, значения - коллекция функций обработчиков, которые будут вызваны при срабатывании события.

Методы класса:  
`on<T extends object>(event: EventName, callback: (data: T) => void): void` - подписка на событие, принимает название события и функцию обработчик.  
`emit<T extends object>(event: string, data?: T): void` - инициализация события. При вызове события в метод передается название события и объект с данными, который будет использован как аргумент для вызова обработчика.  
`trigger<T extends object>(event: string, context?: Partial<T>): (data: T) => void` - возвращает функцию, при вызове которой инициализируется требуемое в параметрах событие с передачей в него данных из второго параметра.

### Данные

#### Интерфейс `IProduct` (товар)

Описывает структуру товара в каталоге.

- `id`: `string` — уникальный идентификатор товара.
- `description`: `string` — подробное описание товара.
- `image`: `string` — URL изображения товара.
- `title`: `string` — краткое название товара.
- `category`: `string` — категория, к которой относится товар.
- `price`: `number | null` — цена товара (может быть `null`, если цена не указана).

#### Интерфейс `IBuyer` (покупатель)

Описывает данные покупателя, необходимые для оформления заказа.

- `payment`: `TPayment` — выбранный способ оплаты (тип `TPayment` определяется отдельно).
- `email`: `string` — электронная почта покупателя.
- `phone`: `string` — номер телефона покупателя.
- `address`: `string` — адрес доставки.

### Модели данных

#### Класс `ProductCatalog` (каталог товаров)

**Назначение**:  
Хранит и управляет коллекцией товаров, доступных для покупки. Отвечает за получение, сохранение и поиск товаров.

**Конструктор**:  
Не принимает параметров. Инициализирует внутренние поля.

**Поля класса**:

- `products`: `IProduct[]` — массив всех товаров в каталоге.
- `selectedProduct`: `IProduct | null` — товар, выбранный для детального просмотра (может быть `null`, если ничего не выбрано).

**Методы**:

- `setProducts(products: IProduct[])`: сохраняет переданный массив товаров в поле `products`.
- `getProducts()`: возвращает массив всех товаров (`IProduct[]`).
- `getProductById(id: string)`: ищет товар по `id` и возвращает его (`IProduct | null`).
- `setSelectedProduct(product: IProduct)`: сохраняет переданный товар в поле `selectedProduct`.
- `getSelectedProduct()`: возвращает текущий выбранный товар (`IProduct | null`).

#### Класс `ShoppingCart` (корзина)

**Назначение**:  
Хранит список товаров, выбранных покупателем для покупки. Обеспечивает добавление, удаление и расчёт стоимости.

**Конструктор**:  
Не принимает параметров. Инициализирует внутреннее хранилище (массив товаров).

**Поля класса**:

- `items`: `IProduct[]` — массив товаров, добавленных в корзину.

**Методы**:

- `getItems()`: возвращает массив товаров в корзине (`IProduct[]`).
- `addItem(product: IProduct)`: добавляет товар в корзину.
- `removeItem(product: IProduct)`: удаляет товар из корзины.
- `clear()`: очищает корзину (устанавливает `items = []`).
- `getTotalPrice()`: рассчитывает и возвращает общую стоимость товаров в корзине (`number`).
- `getItemCount()`: возвращает количество товаров в корзине (`number`).
- `hasItem(id: string)`: проверяет, есть ли товар с указанным `id` в корзине (`boolean`).

#### Класс `Buyer` (покупатель)

**Назначение**:  
Хранит и управляет данными покупателя, необходимыми для оформления заказа. Обеспечивает валидацию и обновление данных.

**Конструктор**:  
Не принимает параметров. Инициализирует поля (изначально — пустые строки или `null`).

**Поля класса**:

- `payment`: `TPayment | null` — выбранный способ оплаты.
- `email`: `string` — электронная почта.
- `phone`: `string` — номер телефона.
- `address`: `string` — адрес доставки.

**Методы**:

- `updatePayment(payment: TPayment)`: обновляет способ оплаты.
- `updateEmail(email: string)`: обновляет email.
- `updatePhone(phone: string)`: обновляет телефон.
- `updateAddress(address: string)`: обновляет адрес.
- `getData()`: возвращает все данные покупателя в виде объекта (`{ payment, email, phone, address }`).
- `clearData()`: сбрасывает все поля в начальное состояние (пустые строки / `null`).
- `validate()`: проверяет валидность данных.  
  **Возвращает**: объект вида `{ [поле]: строка_с_ошибкой }` или пустой объект, если ошибок нет.  
  **Пример возврата**:
  ```json
  {
    "email": "Укажите корректный email",
    "phone": "Номер телефона не может быть пустым"
  }
  ```

### Слой коммуникации

#### Класс `DataService`

**Назначение**:  
Отвечает за взаимодействие с сервером: получение каталога товаров и отправку заказа. Использует экземпляр `IApi` для выполнения HTTP‑запросов.

**Конструктор**:

- Принимает объект, соответствующий интерфейсу `IApi`.

**Методы**:

1. `getProducts()`:

   - Выполняет GET‑запрос на эндпоинт `/product/`.
   - Возвращает `Promise<IProduct[]>` — массив товаров.
   - Обрабатывает ошибки сети/сервера.

2. `sendOrder(orderData: IOrder)`:
   - Выполняет POST‑запрос на эндпоинт `/order/`.
   - Принимает объект `orderData` типа `IOrder`.
   - Возвращает `Promise<boolean>` (успешность отправки).
   - Валидирует данные перед отправкой.

### Слой представления (View)

Все классы представления наследуются от базового класса Component и отвечают за отображение данных в интерфейсе пользователя. Каждый класс работает с определенным DOM-элементом, который передается в конструктор, и предоставляет методы для обновления содержимого этого элемента.

#### Класс Header (шапка сайта)

**Назначение:**

Отображает верхнюю часть страницы, включая логотип и счетчик товаров в корзине. Обрабатывает клик по кнопке корзины для открытия модального окна.

**Конструктор:**

constructor(events: IEvents, container: HTMLElement) - принимает брокер событий для генерации событий и контейнер DOM-элемента.

**Поля класса:**

- counterElement: HTMLElement - элемент для отображения количества товаров в корзине.
- basketButton: HTMLButtonElement - кнопка открытия корзины.

**Методы:**

- set counter(value: number) - устанавливает значение счетчика товаров в корзине.

#### Класс Modal (модальное окно)

**Назначение:**

Управляет отображением и поведением модального окна. Поддерживает открытие, закрытие, установку контента и обработку кликов по оверлею и кнопке закрытия.

**Конструктор:**

constructor(events: IEvents, container: HTMLElement) - принимает брокер событий и контейнер модального окна.

**Поля класса:**

- closeButton: HTMLButtonElement - кнопка закрытия модального окна.
- content: HTMLElement - контейнер для контента модального окна.

**Методы:**

- get isOpen(): boolean - возвращает состояние модального окна (открыто/закрыто).
- set content(value: HTMLElement) - устанавливает содержимое модального окна.
- open(): void - открывает модальное окно.
- close(): void - закрывает модальное окно.

#### Класс Gallery (галерея товаров)

**Назначение:**

Отображает каталог товаров в виде сетки карточек на главной странице.

**Конструктор:**

constructor(container: HTMLElement) - принимает контейнер для галереи.

**Поля класса:**

catalogElement: HTMLElement - контейнер для карточек товаров.

**Методы:**

set catalog(items: HTMLElement[]) - принимает массив элементов карточек и отображает их в галерее.

#### Класс ProductCard (базовая карточка товара)

**Назначение:**

Базовый класс для отображения карточки товара. Содержит общие элементы и методы для всех типов карточек.

**Конструктор:**

constructor(events: IEvents, container: HTMLElement, actions?: ICardActions) - принимает брокер событий, контейнер карточки и опциональные действия по клику.

**Поля класса:**

- category: HTMLElement | null - элемент категории товара.
- title: HTMLElement - заголовок товара.
- image: HTMLImageElement | null - изображение товара.
- price: HTMLElement - цена товара.
- button: HTMLButtonElement | null - кнопка действия (добавить в корзину).
- data: T | null - данные карточки.

**Методы:**

- set category(value: string) - устанавливает категорию товара и соответствующий CSS-класс.
- set title(value: string) - устанавливает название товара.
- set image(value: string) - устанавливает изображение товара (использует CDN_URL).
- set price(value: number | null) - устанавливает цену товара ("Бесценно" для null).
- set buttonText(value: string) - устанавливает текст кнопки.
- set buttonDisabled(state: boolean) - устанавливает состояние disabled для кнопки.

#### Класс CatalogItem (карточка товара в каталоге)

**Назначение:**

Отображает карточку товара в галерее каталога. Обрабатывает клик по карточке для открытия детального просмотра.

**Конструктор:**

constructor(events: IEvents, container: HTMLElement) - наследует от ProductCard.

**Особенности:**

Клик по карточке генерирует событие product:select для открытия превью товара.

Не содержит кнопки "В корзину" в каталоге.

#### Класс PreviewItem (детальная карточка товара)

**Назначение:**
Отображает полную информацию о товаре в модальном окне. Содержит кнопку для добавления товара в корзину.

**Конструктор:**
constructor(events: IEvents, container: HTMLElement) - наследует от ProductCard.

**Особенности:**

Содержит кнопку "В корзину" которая генерирует событие product:add-to-basket.

Отображает состояние кнопки (активна/неактивна/уже в корзине) в зависимости от наличия товара.

#### Класс Basket (корзина)

**Назначение:**

Отображает содержимое корзины покупок в модальном окне. Показывает список товаров, общую сумму и кнопку оформления заказа.

**Конструктор:**

constructor(events: IEvents, container: HTMLElement) - принимает брокер событий и контейнер корзины.

**Поля класса:**

- list: HTMLElement - контейнер для списка товаров.
- total: HTMLElement - элемент для отображения общей суммы.
- button: HTMLButtonElement - кнопка оформления заказа.

**Методы:**

- set items(items: HTMLElement[]) - устанавливает список товаров в корзине.
- set total(value: number) - устанавливает общую сумму заказа.
- set buttonDisabled(state: boolean) - устанавливает состояние кнопки оформления заказа.

#### Класс BasketItem (элемент корзины)

**Назначение:**

Отображает отдельный товар в списке корзины. Содержит информацию о товаре и кнопку удаления.

**Конструктор:**

constructor(events: IEvents, container: HTMLElement) - наследует от Component.

**Поля класса:**

- index: HTMLElement - порядковый номер товара в корзине.
- title: HTMLElement - название товара.
- price: HTMLElement - цена товара.
- deleteButton: HTMLButtonElement - кнопка удаления товара из корзины.

**Методы:**

- set index(value: number) - устанавливает порядковый номер товара.
- set title(value: string) - устанавливает название товара.
- set price(value: number | null) - устанавливает цену товара.

#### Класс OrderForm (форма заказа)

**Назначение:**

Отображает первый шаг оформления заказа: выбор способа оплаты и ввод адреса доставки.

**Конструктор:**

constructor(events: IEvents, container: HTMLElement) - принимает брокер событий и контейнер формы.

**Поля класса:**

- paymentButtons: NodeListOf<HTMLButtonElement> - кнопки выбора способа оплаты.
- addressInput: HTMLInputElement - поле ввода адреса.
- errors: HTMLElement - элемент для отображения ошибок валидации.
- submitButton: HTMLButtonElement - кнопка отправки формы.

**Методы:**

- set payment(value: string) - устанавливает выбранный способ оплаты (подсвечивает активную кнопку).
- set address(value: string) - устанавливает значение адреса в поле ввода.
- set valid(value: boolean) - устанавливает состояние кнопки отправки.
- set errors(value: string[]) - устанавливает сообщения об ошибках валидации.

#### Класс ContactsForm (форма контактов)

**Назначение:**

Отображает второй шаг оформления заказа: ввод контактных данных (email и телефон).

**Конструктор:**

constructor(events: IEvents, container: HTMLElement) - принимает брокер событий и контейнер формы.

**Поля класса:**

- emailInput: HTMLInputElement - поле ввода email.
- phoneInput: HTMLInputElement - поле ввода телефона.
- errors: HTMLElement - элемент для отображения ошибок.
- submitButton: HTMLButtonElement - кнопка отправки формы.

**Методы:**

- set email(value: string) - устанавливает значение email.
- set phone(value: string) - устанавливает значение телефона.
- set valid(value: boolean) - устанавливает состояние кнопки отправки.
- set errors(value: string[]) - устанавливает сообщения об ошибках валидации.

#### Класс Success (экран успеха)

**Назначение:**

Отображает сообщение об успешном оформлении заказа с информацией о списанной сумме.

**Конструктор:**

constructor(events: IEvents, container: HTMLElement) - принимает брокер событий и контейнер экрана.

**Поля класса:**

- description: HTMLElement - элемент для отображения списанной суммы.
- closeButton: HTMLButtonElement - кнопка закрытия экрана.

**Методы:**

- set total(value: number) - устанавливает сумму списанных средств.

### Архитектура MVP (Model-View-Presenter)

**Model** (Модели):

- ProductCatalog - управление каталогом товаров
- ShoppingCart - управление корзиной
- Buyer - данные покупателя

**View** (Представление):

- Header, Modal, Gallery — основные контейнеры
- CatalogItem, PreviewItem, BasketItem — карточки товаров
- OrderForm, ContactsForm, Success — формы и экраны
- ProductCard — базовый класс для карточек
